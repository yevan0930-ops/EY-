# Word Quest

A small English vocabulary study page for U.S. sixth-grade learners. It includes flashcards, audio pronunciation, a multiple-choice quiz, example sentences, and locally saved progress.

## Publish with GitHub Pages

1. Upload `index.html` to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` publishes the site.
